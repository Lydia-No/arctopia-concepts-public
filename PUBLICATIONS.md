## Evidence-status rule

ArcTopia keeps the following distinct:

- conceptual proposition;
- public working paper;
- manuscript or working paper under development;
- implemented technical demonstrator;
- empirical result;
- validated operational system.

One does not automatically establish another.

## Repository rule for manuscripts

Where a paper already has a stable DOI or SSRN record, this repository should link to the public record rather than store duplicate manuscript copies.

Working drafts, private appendices, review correspondence, implementation notes, and patent-sensitive technical material do not belong in the public repository.
